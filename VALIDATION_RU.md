## Семь тестовых сценариев

1. Пути к CSS, JavaScript, favicon и CV на корневом адресе и в подпапке проекта для всех трёх языков.
2. Полнота переводов, реальные DOM-элементы для переводов, переключение языка и сохранение выбора.
3. Смена языка сохраняет выбранную технологию, вкладку кода и историю терминала. Ввод терминала не интерпретируется как HTML.
4. Перемещение клавиатурой меняет DOM-порядок, сохраняет его после повторной загрузки и поддерживает сброс.
5. Pointer-события перетаскивания, в том числе имитирующие touch; перенос после отпускания и отмена через Escape.
6. Повреждённые настройки и недоступное localStorage не ломают интерфейс.
7. Копирование email/кода, переключение вкладок и проектные ссылки работают после перевода и перестановки карточек.

## Ограничения проверки

- Тесты выполнены в jsdom, без браузерной отрисовки. Они не подтверждают отсутствие визуальных наложений или особенности жестов конкретного телефона.
- Внешние URL проектов не проверялись на HTTP-доступность в рамках этого этапа.
- GitHub workflow подготовлен и проверен локально, но ещё не запускался в пользовательском репозитории.
- Сайт на GitHub ещё не опубликован. Перед первым запуском требуется включить Pages с Source = GitHub Actions.
- В npm есть предупреждение об устаревшем транзитивном пакете `whatwg-encoding` в зависимости для тестов jsdom. Оно не препятствовало сборке или тестам; jsdom не входит в опубликованный `dist/`.

## Контрольная сумма CV

```text

```

Контрольные суммы остальных файлов перечислены в `SHA256SUMS`. В Linux проверить:

```bash
sha256sum -c SHA256SUMS
```

После собственных изменений контрольные суммы закономерно изменятся.
